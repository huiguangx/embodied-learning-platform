# EIP 训练平台页面采集

## 已确认的主流程

1. 在首页确认集群健康度、GPU 利用率和可用计算节点。
2. 在资产中查看训练镜像，以及对象存储中的数据和产物路径。
3. 在资源中选择合适的队列和资源组（菜单入口存在，当前未进入具体页）。
4. 在“自定义训练”创建或复制已有任务，指定框架、队列、优先级、实例和 GPU 资源。
5. 在同一任务列表跟踪状态、开始/结束时间与运行时长；需要交互环境时转至“开发机”。

## 菜单结构

- 个性看板：训练任务、开发机、任务统计。
- 训练 & 推理：开发机、自定义训练、弹性资源任务、实验管理、在线服务。
- 资产：镜像中心、对象存储、模型仓库。
- 资源：队列管理、预约计划、资源组。
- 管理、模型定制、服务器状态：存在一级入口，未在本轮可访问页面中展开采集。
